# g-mini-client

Ультралёгкий SPA-клиент для блокчейна Голос, построенный по философии «Bring Your Own Client». Вся логика (чтение, публикация, голосование) выполняется напрямую из браузера через `golos-lib-js`.

## Как запустить

Есть два способа запустить клиент:

### 1. Онлайн (Рекомендуется)
Самый простой и надёжный способ — открыть клиент по ссылке (GitHub Pages):
**https://seminthai.github.io/g-mini-client/**

*В этом режиме работают все функции, включая воспроизведение YouTube.*

### 2. Локально (Скачать файл)
Клиент можно скачать и запустить локально как обычный HTML-файл. 

⚠️ **Внимание:** Если открыть файл двойным кликом (через `file://`), **встроенные видео YouTube не будут воспроизводиться** (ошибка 153). Это ограничение безопасности самого YouTube, которое невозможно обойти на уровне кода клиента. Все остальные функции работают в штатном режиме.

**Если вы хотите запустить клиент локально и смотреть YouTube:**
1. Скачайте папку с клиентом.
2. Откройте терминал (командную строку) в этой папке.
3. Запустите локальный сервер. Например, если у вас установлен Python:
   ```bash
   python -m http.server 8000
   ```
   (или `python3 -m http.server 8000`)
4. Откройте в браузере `http://localhost:8000`.

*В этом случае браузер будет считать страницу «сайтом», и YouTube заработает.*


## Авторизация

Для полноценной работы (голосование, комментарии, публикация постов, подписка) необходимо авторизоваться.

1. Нажмите кнопку **«Авторизация»** в правом верхнем углу.
2. Введите **имя пользователя** (без символа `@`).
3. Введите ваш **Posting-ключ** (WIF). 
   * *Это безопасный ключ, который используется только для публикации и голосования. Не используйте Active или Owner ключи.*
4. Нажмите **«Войти»**.

**Важно:** 
- Если вы хотите, чтобы клиент запомнил вас на этом устройстве, поставьте галочку **«Запомнить меня»**. Ключ сохранится в локальном хранилище браузера (`localStorage`). 
- Если галочка не стоит, ключ будет храниться только в оперативной памяти до закрытия вкладки.
- В любой момент вы можете выйти из аккаунта, нажав кнопку **«Выйти»**.

## Что уже реализовано

- **Чтение:** Ленты «Новое», «Моя лента», «Мой блог».
- **Публикация:** Редактор с поддержкой Markdown, предпросмотром, выбором категории, тегов и настроек выплат (50/50 или 100% SP).
- **Медиа:** Встраивание YouTube (обычные видео и Shorts), SoundCloud, Rutube, VK и других сервисов (через iframe с белым списком доменов).
- **Взаимодействие:** Голосование (с выбором веса и проверкой active_votes), комментарии (рекурсивное дерево с поддержкой смайлов), подписка/отписка на авторов.
- **Профили:** Аватары, репутация, список последних постов с пагинацией.
- **Упоминания:** Уведомления о новых упоминаниях и ответах на ваши посты (настраиваемый период, отметка «прочитано»).
- **Кросспостинг:** Перехват ссылок на `golos.id`, `golos.today` и др. для открытия внутри клиента.
- **Блокчейн-нативные ссылки:** Формат `@author/permlink` распознаётся как кликабельная ссылка (работает и в постах, и в редакторе).
- **Редактирование:** Редактирование опубликованных комментариев и постов.

## Замечания

- **Маркдаун:** В редакторе поддерживается только чистый Markdown. HTML-теги (кроме iframe для медиа) не обрабатываются, чтобы избежать «каши» в постах.
- **Безопасность:** Вставленные iframe фильтруются по белому списку доменов. Вредоносные скрипты не пройдут.
- **Кэширование:** Если вы обновили файлы на сервере, но видите старую версию — используйте жёсткую перезагрузку (`Ctrl + F5`).
